# 2026 특수교육지도사 사과나무 연수 · 조/숙소 찾기

연수 참가자가 휴대폰에서 **자기 이름을 검색하면 본인 조와 숙소 호실, 같은 조·같은 방 사람**을 바로 확인할 수 있는 한 페이지짜리 웹앱입니다.

| | |
|---|---|
| 연수 | 2026 특수교육지도사 사과나무 연수 (1박 2일, 08.10~08.11) |
| 규모 | 150명 · 15개 조(조당 10명) · 숙소 50실(3인 1실) |
| 배포 | GitHub Pages |

## 기능

- **이름 검색** — 이름, 학교명, 지역, `7조`, `19호`, 초성(`ㄱㄱㅇ`)으로 조회
- **동명이인 처리** — 같은 이름이 여러 명이면 소속·지역·조·호실을 붙여 선택 목록으로 안내
- **내 정보 저장** — 한 번 찾아두면 다음 접속 때 바로 본인 카드가 열림 (기기에만 저장)
- **조별 / 호실별 전체 명단** — 하단 탭에서 접었다 펴며 확인
- **홈 화면에 추가** — 아이콘·전체화면을 지원하는 PWA (manifest + 아이콘)

## 개인정보 보호

명단은 실명과 소속 학교를 담고 있어 **평문으로 저장소에 올리지 않습니다.**

- `index.html` 안에는 **AES-256-CBC로 암호화된 명단**만 들어 있습니다.
  키는 입장 암호에서 PBKDF2-SHA256(40만 회)으로 유도하며, 복호화는 브라우저(WebCrypto)에서만 일어납니다.
- 암호를 모르면 파일을 내려받아도 이름을 읽을 수 없습니다.
  다만 **암호가 짧으면 대입 공격으로 뚫릴 수 있습니다.** 검색 노출과 우연한 열람을 막는 수준으로 보시고,
  민감도가 더 높아지면 저장소를 비공개로 돌리는 편이 안전합니다.
- 검색엔진 색인은 `noindex, nofollow, noarchive` 로 차단했습니다.
- 원본 엑셀과 복호화된 `build/data.json` 은 `.gitignore` 로 제외됩니다.

## 명단이 바뀌었을 때

1. `build/data.json` 을 최신 명단으로 교체합니다. 한 사람이 객체 하나입니다.

   ```json
   [{ "seq": 1, "team": "1조", "region": "01. 수원", "pub": "공립", "lvl": "유",
      "org": "매산유치원", "name": "강기옥",
      "room": "1", "roomNo": "216호", "roomKind": "동일지역·동일조" }]
   ```

   `roomNo` 가 화면에 표시되는 실제 호실번호이고, `room` 은 배정표의 내부 순번입니다.

2. 다시 빌드합니다. `-Password` 를 바꾸면 입장 암호가 바뀝니다.

   ```powershell
   powershell -ExecutionPolicy Bypass -File build\make-site.ps1 -Password 7766
   ```

3. 커밋 후 푸시하면 GitHub Pages에 자동 반영됩니다(보통 1분 내외).

   ```bash
   git commit -am "명단 갱신" && git push
   ```

## 구성

```
index.html              배포되는 앱 전체 (스타일·로직·암호화된 명단 포함)
manifest.webmanifest    홈 화면 추가용 설정
icon-192/512.png        앱 아이콘
build/body.html         화면과 로직의 원본 템플릿
build/make-site.ps1     명단 암호화 + index.html 생성
build/make-icons.ps1    아이콘 생성
```

`index.html` 을 직접 고치지 마세요. `build/body.html` 을 고친 뒤 `make-site.ps1` 을 다시 실행하면 됩니다.
